# 真实纹样图片测试报告（2026-11-12）

> 素材: `images/`（8 张，来源与授权见 `images/SOURCES.md`）
> 测试脚本: `demos/demo_real_images.py` · 输出: `demos/output/real_test_*.png`

## 1. 素材来源

8 张 1086×1448 高清纹样卡片来自开源项目「中国传统纹样图鉴 Wenyàng」
（github.com/dososo/chinese-traditional-patterns，CC BY-NC 4.0，研究/非商用
范畴），覆盖四大类：花卉（宝相花/牡丹/莲瓣）、卷草、几何（回纹/云雷/冰裂）、
文字（团寿）。每张附元数据（中英名/类别/寓意），见 `images/manifest.json`。

## 2. 测试设置

每张图走完整链路：**卡片图 → OpenCV 预处理（Otsu + 前景占比自适应反色 +
闭运算）→ 掩膜阶段剥离边框带/标题栏（`strip_border_band`，四边 28px +
顶部 12%）→ 部件分解（自动选阶，max K=24，tol=1.0px）→ 填色重建**
（按面积升序渲染，小部件后画）。

## 4. 关键发现（含迭代过程）

1. **事后丢部件是错误思路**（第二轮回归教训）：纹样主体通过卡片装饰
   边框与图边连通成单一连通域，按 bbox 丢"边框部件"会把主体一起丢掉
   ——五张图主体从重建中消失，且 RMS"改善"是丢最难部件的统计假象。
   正确做法是**掩膜阶段剥边框带**，切断连通让主体独立成域（主体像素
   保留率实测 100%）。
2. **剥离带宽度**：12px 只切断边框与图边，边框环内圈（距边 16–23px）
   仍存活导致主体经其连体；加宽到 28px 覆盖内圈后改善。残余连体
   （如宝相花与右缘竖排装饰连体，单部件 27 万 px）是卡片版式固有
   情况，继续加宽会切掉真主体——作为已知特性记录。
3. **几何类纹样是 EFD 的甜点**：回纹 29px、云雷纹 54px、卷草纹 69px，
   规整曲线结构低阶即可高精度重建。
4. **文字/锐折角是已知弱点**：团寿"寿"字直角笔画（RMS 115px）、冰裂
   网格细线（268px）K=24 仍未收敛——EFD 的 Gibbs 特性。后续方向：
   文字类部件分段编码。
5. **tol=1.0px 对真实素材偏严**：大量部件顶到 max K=24（像素锯齿对
   EFD 是高频细节）。正式实验建议 tol=1.5–2px 或先形态学平滑。
6. **预处理自适应有效**：8 张米白底彩卡 Otsu+反色判据全部选对方向。

## 5. 对论文的意义

- 8 类纹样（花卉/卷草/几何/文字）的分解指标可直接进论文量化表格；
- `real_test_*.png` 三联图（原图/掩膜/重建）可作论文图；
- 三轮验收迭代的方法论教训（连通域陷阱、统计假象）本身是实验章节
  值得报告的内容；
- 已知弱点（文字直角、锯齿敏感、连体部件）为"对称聚类归并 + 分段
  编码"两个后续工作提供动机。
