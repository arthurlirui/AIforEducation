# 波点艺术流派与数学原理调研报告

> 项目：AIforDotArt —— 点描/波点艺术生成器
> 日期：2026-10-14
> 范围：波点（dot-based）艺术的主要流派、构图与技法的数学原理，及其在计算图像生成上的落地

---

## 1. 总览：从"点"出发的艺术史

"以点作画"并非单一流派，而是一条横贯印刷史、现代艺术与计算图形的谱系：

| 流派 / 方向 | 代表人物 / 文献 | 核心思想 | 核心数学对象 |
|---|---|---|---|
| 新印象派·点彩 (Pointillism / Divisionism) | Seurat、Signac (1884–) | 纯色小点在视网膜上"光学混合" | 空间化加法混色、互补色理论 |
| 同时对比色论 | Chevreul 1839 | 并置颜色互相诱导对方补色 | 色轮对径补角 (Δh = 180°) |
| 半调 / Ben-Day 印刷点 | Ben Day 1879；Lichtenstein | 用规则点阵的覆盖率模拟灰度 | 网点角度屏、面积率-灰度映射 |
| 波普的挪用 | Lichtenstein (1960s) | 把印刷网点当美学本身 | 正交点阵 + 原色 (CMYK 式) |
| 草间弥生·无限网 & 波点 | 草间弥生 (1950s–) | 重复到消解形体/背景、"直到无限" | 准周期密铺、变形场 |
| 加拿大原住民 / 澳洲原住民点画 | (古老传统) | 同心圆、连"线"的点列 | 等距圆有限集、路径点采样 |
| 欧普艺术 (Op Art) | Vasarely ("Vega")、Riley | 点阵经变形/移位产生运动与凸起幻觉 | 位移场、径向膨胀映射 |
| 计算点绘 / 蓝噪声采样 | Secord 2002；Ulichney 1988 | 用"均匀但不规则"的点逼近任意灰度图 | 加权质心 Voronoi (WCVT)、重要性采样 |

统一视角：**所有流派都可以写成「点集 P = {(x_i, r_i, c_i)} ⊆ 画布 × 半径 × 颜色」的生成问题**。区别只在于：
1. 点**位置**由什么决定（网格 / 密度场 / 黄金角 / 变形场）；
2. 点**半径**由什么决定（常数 / 密度反函数 / 径向函数）；
3. 点**颜色**由什么决定（原图采样 / 互补混合 / 固定图谱）。

本项目的生成代码（`dotart.py`）就按这三个算子来组织。

## 2. 各流派的数学原理

### 2.1 点彩派（Seurat 的新印象派）：视网膜上的加法混合

**史实**：Seurat《大碗岛的星期天下午》(1884–86) 用等大的纯色笔触覆盖画面；理论源头是 Chevreul《论色彩的同时对比》(1839) 与 Ogden Rood 的光学色彩著作。Chevreul 也是哥白林织毯厂染色总监，他发现"颜色不够鲜艳"是**光学**问题而非染料问题——并置的两色各自向对方投射自己的补色（同时对比定律）。他还明确讨论过"以一团单色小点"产生混色效果的方案。

**数学模型**。设眼睛是一个空间低通滤波器，核为 Gσ（视角距离 σ）：

$$I_{\text{seen}}(x) = (G_\sigma * I_{\text{canvas}})(x)$$

当点的直径 d 远小于衍射/视角分辨率（经验上 d < σ 的若干分之一）时，卷积近似面积加权平均：

$$I_{\text{seen}}(x) \approx \sum_{k} w_k(x)\, C_k,\qquad \sum_k w_k = 1$$

即**加法混色**（色光混合）：把目标色 T 分解成若干纯色点 {C_k} 的面积比 {w_k}，近距离看到点阵、远看（下采样）得到 T。因此工程实现上等价于一个**按权重的空间抖动 (dithering)**：

- 对每个像素邻域的目标 RGB，取色板上有限个纯色，求解线性组合（或取通道分解+近邻量化）；
- 用抖动把量化误差撒到邻域，保持局部能量守恒（Floyd–Steinberg 误差扩散是其一）；
- 关键的 Chevreul 经验：**同时对比**使并置补色（Δh ≈ 180°）比通道分解的混色更"跳"、更亮——Seurat 恰恰用橙色点笔触提亮蓝色海面而非用灰色压暗天空。

**构图数学**：Seurat 的画面大量用竖直/水平基准线 + 斜向偏移，以及"横带式 (frieze)"构图（仿帕特农神庙泛雅典娜游行浮雕，人物一排排侧向平移）。这对应：
- 主导矢量场沿水平/竖直扫描；
- 低频空间频率上用阻尼正交网格；
- 重音点落在对分点（黄金分割 1/φ ≈ 0.618 处），见 §2.6。

### 2.2 半调网点 (Halftone) 与 Ben-Day / Lichtenstein

**史实**：Benjamin Henry Day Jr. 1879 年取得 Ben-Day dots 专利；印刷业随后确立 CMYK 四色网点工艺。Lichtenstein 1960 年代把这套印刷技术**放大到画布**上，让网点本身成为主题。

**数学模型**。固定网格周期 λ、网点角度 θ，每个网格单元的覆盖率 a(x) = π r(x)² / λ² （对圆形网点），它即"灰度"：

$$r(x) = \lambda \sqrt{\frac{a(x)}{\pi}},\qquad a(x) = 1 - g(x)$$

其中 g(x) 是归一化图亮度。印刷中为消除莫尔纹，各色版采用标准网点角（青 15°、品红 75°、黄 0°、黑 45°）——两条周期点阵叠加的莫尔频差 Δf 在角度差 30°/60° 时最小、在接近平行时最大，这又是纯粹的拍频 (beat frequency) ##现象。

**波普的挪用**：Lichtenstein 保留了"Benday 点大、间距大、角度正交"的外观，点从"手段"变成"主题"，颜色简化为红黄蓝白黑。因此生成实现很直接：等距正交网格 + 半径-灰度映射 + 固定图谱色。

### 2.3 草间弥生：无限网、波点、消解形体

**史实**（MoMA / 草间弥生美术馆 / QAGOMA）：
- 无限网 (Infinity Nets, 1959–)：在白底上以近乎同一色的短线套娃式勾出密集小弧环。她自述"用自我消解的方式，无限地走向尽头"。
- 波点 (polka dots)：重复圆点直到背景与主体互相湮灭 (obliteration)。
- 南瓜母题、黄底黑斑是其经典配色。

**数学模型**：
1. **无限网** ≈ 一个**准周期网**：把周期点阵的坐标加上低频变形场：

$$\tilde{x} = x + A\,\bigl[\sin(\omega_1 x + \phi_1),\ \sin(\omega_2 y + \phi_2)\bigr]$$

A ≪ λ（网格常数）保证"看得见的重复 + 细微错位"的质感。弧线本身可以画成小圆环段（极坐标上一段圆弧），半径 r ∼ λ/3。

2. **波点尺寸分级**：草间的点并非等大，而是**半径概率分布**：在"平铺底点 + 大圆点覆在上面"的双层结构中 p(r) 是双峰分布。配合黄-黑强对比与留白，让观者视线沿大圆-小圆簇流动。

3. **消解形体 = 密度归一**：要让点均匀湮灭形体，就把点的**密度场**做成与图像亮度近似无关，让点"越过"边界。这与重要性采样做相反操作，见 §2.5。

### 2.4 原住民点画 / Aboriginal dot painting

同心圆与连点成线。数学上：
- 同心圆弧：极坐标下 r_n = r_0 + n·Δ，θ 取有限集合；
- 连点线：对路径 γ: [0,1] → 画布做点采样 x_i = γ(i/n)，形成"虚线路径"。
数据上基本自由，技术负担在**路径生成**而非点放置，故本项目不单独实现生成器，仅作为背景介绍。

### 2.5 计算点绘 (Computational Stippling)：从 Secord 到蓝噪声

**关键文献**：
- Secord, *Weighted Voronoi Stippling*, NPAR 2002；
- Ulichney, *Dithering with blue noise*, Proc. IEEE 1988；
- McCool & Fiume, *Hierarchical Poisson disk sampling*, GI 1992。

**问题**：给定灰度图 ρ(x)（密度场），生成 N 个点，使得点的"出现概率"正比于 ρ 且点之间**既不聚集也不成格**（蓝噪声谱：低频能量少，中频平坦）。

**两种经典解法**：

(a) **拒绝采样 + 密度插值（本项目采用）**：每次从 ρ(x) 归一化后的 PDF 做逆变换采样，采样前用当前点集的最小距离 r_min(x) 做马尔可夫约束：当局部密度高时允许小 r_min，密度低时增大 r_min。达到 N 为止。 radii 用映射

$$r_i = r_0\cdot \bigl(\rho(x_i)\bigr)^{-\alpha},\qquad \alpha \approx 1/2$$

使得点占据的"面积 × 密度"近似恒定 — 即每个点代表相同的墨水总量。

(b) **Lloyd 松弛 / WCVT（加权质心 Voronoi）**：把点 {x_i} 反复更新为其 Voronoi 单元的加权质心

$$x_i \leftarrow \frac{\int_{V_i} x\,\rho(x)\,dx}{\int_{V_i} \rho(x)\,dx}$$

数轮后得到"等质心等面积"的点阵，蓝噪声性质很好。为保证实现简单，本项目用 (a) + 邻近查表（scipy `cKDTree`），并给出可选的一轮松弛可加性（未实现）。

### 2.6 黄金角与叶序 (Phyllotaxis)

Vogel 模型：第 n 个芽

$$r_n = c\sqrt{n},\qquad \theta_n = n\cdot\alpha,\qquad \alpha = 2\pi(1 - 1/\varphi) \approx 137.508°$$

即黄金角。由于 φ 是最无理数（连分数 [1;1,1,1,…]），点在极坐标下既均匀又不会形成肉眼可见的径向臂，除非 n 足够大出现裴波那契螺线。用它做构图：
- 把主体放在黄金分割点 (0.618 w, 0.618 h)；
- 用中心-向外的 Vogel 点列让观者视线螺旋进入画面；
- 把点的半径 r_n ∝ 1/n^β 控制"远处点更密"的辐射衰退。

## 3. 本项目生成器架构

`dotart.py` 把上面六套模型做成六个 mode：

```
mode = { seurat | kusama | benday | warp | stipple | vogel }
                 ▲                ▲             ▲          ▲
                 │                │             │          └─ 黄金角 (φ)
                 │                │             └─ WCVT-style 重要采样
                 │                └─ 正交网格 + 半径-灰度
                 └─ 互补色两色分解 + 空间抖动
```

数据流：

```
输入图像 I ∈ [0,1]^{H×W×3}
  ├─ 亮度密度 ρ ← Luminance(I)（或 ρ = 1 常密度）
  ├─ 位置采样 sampler(ρ) ∈ {uniform-grid | poisson | vogel}
  ├─ 半径函数 r(x)（常量 | r0·ρ^{-1/2} | 双峰混合）
  └─ 颜色函数 c(x)（采样 I(x) | 互补抖动 | 固定图谱）
渲染：PIL 绘制圆盘，输出 RGB PNG
```

所有模式都在 ~1500 行的单文件 `dotart.py` 中完成，且**没有深度学习依赖**，numpy + PIL + scipy 即可。
