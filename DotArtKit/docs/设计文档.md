# DotArtKit 敟一波点艺术生成项目 — 设计文档

> **版本**: 1.0.0
> **日期**: 2026-10-18
> **作者**: AIforEducation Project
> **范围**: 把 `AIforPolkaDotsArt` (草间弥生专攻 + 深度感知) 与 `AIforDotArt` (多流派纯数学) 两个独立子项目整合为单一 Python 包 `DotArtKit`, 并给出统一架构、模块边界、依赖策略与扩展指南.

## 1. 项目背景与整合动机

### 1.1 两个前身项目

`D:\Code\AIforEducation\` 下原有两个独立的波点艺术生成子项目:

| 项目 | 完成日期 | 范围 | 依赖 |
|------|----------|------|------|
| **AIforPolkaDotsArt** | 2026-10-07 → 10-12 | 草间弥生风格专攻: 基础版 (亮度密度 Voronoi) + 深度感知版 (YOLO26 深度 + 三层架构 + 语义双色), 配 IJCAI'26 Arts 论文 | numpy / scipy / opencv / ultralytics / torch |
| **AIforDotArt** | 2026-10-14 | 多流派纯数学: 6 模式 (Seurat 点彩 / Kusama 双峰 / Ben-Day 半调 / Vasarely 欧普 / Secord 点绘 / Vogel 黄金角), 无 DL 依赖 | numpy / PIL |

### 1.2 整合动机

两个项目存在三重重叠与割裂:

1. **算法谱系同源**: 都属于"点集 `{(x_i, r_i, c_i)}`"生成问题, 区别只在位置 / 半径 / 颜色三个算子的来源. 两个项目各自实现了一套 `kusama` 生成函数 (`AIforDotArt/dotart.py::generate_kusama` 与 `AIforPolkaDotsArt/kusama.py::kusama_polka`), 风格相似但实现不同.
2. **依赖策略冲突**: `AIforPolkaDotsArt` 依赖 scipy (Voronoi Lloyd), 本机 scipy 1.x 与 numpy 2.x 二进制不兼容; `AIforDotArt` 绕开 scipy 用纯 numpy `GridHash`. 整合后可让两套实现共存, 按可用性自动降级.
3. **复用基础设施**: 两项目都实现了 HSV 转换、亮度计算、圆点绘制、近邻查询等工具函数, 整合到 `ops/` 子包后单一来源, 消除重复.

### 1.3 整合目标

- **单一 Python 包** `dotartkit`, 统一 API `generate(mode, image, **kwargs)` 覆盖全部 8 种流派
- **算子分层架构**: 底层算子 (`ops/`)、中层流派渲染器 (`styles/`)、上层 API/CLI
- **依赖分级**: 核心 (numpy + PIL + opencv) 必需; scipy / ultralytics / torch 全部可选, 缺失时优雅降级
- **保留原项目资产**: 调研报告、IJCAI 论文、YOLO26 权重、实验脚本全部迁入, 不丢失
- **统一设计文档**: 本文档作为整合后的权威设计依据

## 2. 统一视角: 点集生成的三算子模型

整合的核心抽象来自 `AIforDotArt/调研报告_波点艺术流派与数学原理.md` §1 的总结:

> 所有流派都可以写成「点集 `P = {(x_i, r_i, c_i)} ⊆ 画布 × 半径 × 颜色`」的生成问题. 区别只在于:
> 1. 点**位置**由什么决定 (网格 / 密度场 / 黄金角 / 变形场)
> 2. 点**半径**由什么决定 (常数 / 密度反函数 / 径向函数)
> 3. 点**颜色**由什么决定 (原图采样 / 互补混合 / 固定图谱)

本包按这三个算子组织代码, 每个流派 = 三个算子的特定组合:

| 流派 | 模式键 | 位置算子 | 半径算子 | 颜色算子 | 依赖 |
|------|--------|----------|----------|----------|------|
| 点彩派 | `seurat` | 网格 + 抖动 | 常数 | 互补色面积混合 (Bayer 抖动) | 纯 numpy |
| Ben-Day 半调 | `benday` | 旋转网格 | `r = λ·sqrt((1-g)/π)` | Lichtenstein 四色 (hue 量化) | 纯 numpy |
| Vasarely 欧普 | `warp` | 径向变形网格 | 凸起函数 + 亮度 | 单色 + 亮度调制 | 纯 numpy |
| Secord 点绘 | `stipple` | 密度拒绝采样 + GridHash | `r ∝ ρ^(-1/2)` | 单色 | 纯 numpy |
| 黄金角叶序 | `vogel` | Vogel 螺线 `r_n=c√n, θ_n=n·137.508°` | 中心大 + 亮度 | 原图采样 + 提饱和 | 纯 numpy |
| 草间弥生 (基础) | `kusama_basic` | Voronoi Lloyd + 多层 | 密度正向映射 (暗=大) | 调色板 + 边缘 + horror vacui | numpy + scipy (退化) |
| 草间弥生 (深度) | `kusama_depth` | 深度复合密度场 | 深度映射 `r = r_min + (r_max-r_min)·(1-d̂)^α·(1+ε)` | 语义双色 (前景/背景) | numpy + ultralytics + GPU |
| 可学习映射 | (扩展 `learned`) | 同 kusama_depth | CNN 预测 (替代固定幂律) | 同 kusama_depth | + torch |

**关键设计原则**: 上层只依赖下层的接口, 不依赖具体实现. `ops/` 不做风格化决策, 只提供数学原语; `styles/` 组合算子实现具体流派; `api.py` 仅做模式分派.

### 3.3 依赖分级策略

| 层级 | 依赖 | 缺失时行为 |
|------|------|-----------|
| 核心 | numpy, Pillow, opencv-python | 必需, 缺失则包不可导入 |
| scipy | scipy.spatial (Voronoi, cKDTree) | `ops/voronoi.py::has_scipy()` 返回 False; `stipple()` 跳过 Lloyd 松弛, `prune_overlapping` 退化到 O(n²) 纯 numpy |
| ultralytics | YOLO26 深度 + 语义分割 | `ops/depth.py::has_ultralytics()` 返回 False; `kusama_depth` 模式实例化时抛 ImportError (无法降级, 因为深度感知是核心特性) |
| torch | DepthRadiusNet 可学习映射 | `learned.py::has_torch()` 返回 False; 类定义占位符, 实例化抛 ImportError; 其余流派完全不受影响 |

依赖探测在模块导入时用 `try/except` 完成, 不会因缺失可选依赖而阻塞包导入. 用户可通过 `dotartkit.has_scipy() / has_ultralytics() / has_torch()` 查询运行时能力.

## 4. 模块详细设计

### 4.1 `ops/color.py` — 颜色与亮度原语

**职责**: 提供所有流派共享的像素级工具, 不做任何风格化判断.

**函数**:
- `to_float01(img)` — PIL → float32 RGB ∈ [0,1]
- `luminance(rgb)` — Rec.709 亮度
- `rgb_to_hsv(rgb)` / `hsv_to_rgb(hsv)` — 向量化 HSV 转换 (h ∈ [0,1))
- `sample_color(img, pts)` — 双线性采样
- `draw_disks(canvas, pts, radii, colors)` — PIL 圆点绘制

**调色板常量**:
- `KUSAMA_PALETTES` — 草间基础版 6 色板 + 2 扩展色板, BGR (cv2) 元组
- (深度感知版调色板 `DEPTH_PALETTES` 在 `ops/depth.py`, 因为含语义双色结构)

**来源**: 合并自 `AIforDotArt/dotart.py` 顶部工具函数 + `AIforPolkaDotsArt/kusama.py::PALETTES`.

### 4.2 `ops/grid.py` — 网格哈希近邻查询

**职责**: O(1) 近邻最小距离约束, 替代 `scipy.spatial.cKDTree`.

**类**: `GridHash(cell)` — 固定 cell 大小的空间哈希.
- `far_enough(x, y, r)` — 查询 (x,y) 是否距所有已加入点 ≥ r
- `add(x, y)` — 加入新点

**来源**: 迁自 `AIforDotArt/dotart.py::_GridHash`. 在 scipy 不可用时供 `stipple_pure` 与 `voronoi.prune_overlapping` 退化路径使用.

### 4.3 `ops/voronoi.py` — Secord WCVT 核心

**职责**: 实现 Secord (2002) 加权质心 Voronoi 图迭代点绘算法.

**函数**:
- `compute_density(gray, gamma, invert)` — 灰度 → 归一化密度场
- `rejection_sample(density, n, rng)` — 按密度概率采样
- `voronoi_filtered(points, W, H)` — 镜像点 Voronoi (处理无界单元), **scipy 必需**
- `weighted_centroid_cumsum(vertices, density, P, Q)` — cumsum 加速密度加权质心
- `lloyd_relax(points, density, n_iter, rng)` — Lloyd 松弛, **scipy 必需**
- `prune_overlapping(points, radii, gap)` — 密度自适应贪心剪枝, scipy 缺失时退化到 O(n²)
- `stipple(density, n_points, ...)` — 完整点绘 pipeline, scipy 缺失时跳过 Lloyd
- `has_scipy()` — 运行时能力查询

**来源**: 迁自 `AIforPolkaDotsArt/stippling.py`, 加入 scipy 退化路径.

### 4.4 `ops/depth.py` — YOLO26 深度 + 语义 + 算法函数

**职责**: 封装 YOLO26 深度估计与语义分割模型 (DL 部分), 以及深度归一化、深度→半径 / 深度→密度等纯 numpy 算法函数 (非 DL 部分).

**DL 类** (ultralytics 必需):
- `DepthEstimator` — YOLO26 单目深度, 输入 BGR uint8, 输出 (H,W) float32 metric depth (米)
- `SemanticSegmentor` — YOLO26 语义分割 (Cityscapes 19 类), 输出 (H,W) uint8 类 ID

**纯 numpy 算法**:
- `normalize_depth(depth, ...)` — 深度归一化到 [0,1], 0=最近, 1=最远, 支持百分位裁剪
- `normalize_depth_foreground(depth, fg_mask, ...)` — 仅用前景区域深度范围归一化, 放大前景物体内部深度差
- `depth_to_radius(d_norm, r_min, r_max, alpha, sigma, rng)` — 深度→半径映射 `r = r_min + (r_max-r_min)·(1-d̂)^α·(1+ε)`
- `depth_to_density(d_norm, gray, gamma, beta)` — 复合密度场 `ρ = (1-d̂)^β · γ(I)`
- `depth_aware_stipple(density, d_norm, ...)` — 深度感知点绘 (位置由密度驱动, 半径由深度调制)
- `analyze_semantic_regions(seg)` — 连通语义区域分析 (cv2)
- `get_foreground_mask(seg, min_area_ratio)` — 从 Cityscapes 分割提取前景掩码

**调色板**: `DEPTH_PALETTES` — 5 个深度感知版调色板, 每个含 `bg / fg_dot / bg_dot` 三色 (BGR).

**来源**: 拆分自 `AIforPolkaDotsArt/depth_kusama.py`, 把 DL 封装与纯算法分离, 使算法部分在无 ultralytics 时仍可单独测试.

### 4.5 `styles/` — 流派渲染器

每个流派一个文件, 实现 `generate_<name>(image: PIL.Image, **kwargs) -> PIL.Image`. 所有流派接收 RGB PIL Image, 输出 RGB PIL Image, 签名统一.

草间弥生两个流派额外提供文件路径接口 (`kusama_polka` / `depth_kusama_polka`), 保留与原项目脚本的兼容性, 内部用临时文件桥接 PIL 接口.

**`styles/seurat.py`** — 点彩派. Chevreul/Rood 互补色面积混合 + Bayer 4×4 抖动.

**`styles/benday.py`** — Ben-Day 半调 / Lichtenstein 波普. 旋转网格, `r = λ·sqrt((1-g)/π)`, 四色图谱 (红/黄/蓝/黑) 按 hue 量化.

**`styles/warp.py`** — Vasarely Vega 欧普凸起. 径向变形场 `amp ∝ 1-(2r/R-1)²`, 亮度调制点尺寸/明暗.

**`styles/stipple_pure.py`** — 纯 numpy Secord 点绘. 密度拒绝采样 + `GridHash` 最小距离约束, `r ∝ ρ^(-1/2)`. 与 `kusama_basic` 的区别: 不用 scipy Voronoi Lloyd, 在 scipy 不可用时仍可运行.

**`styles/vogel.py`** — 黄金角叶序. `r_n = c·√n, θ_n = n·137.508°`, 沿斐波那契螺线从中心铺开, 亮度调制半径与颜色.

**`styles/kusama_basic.py`** — 草间基础版. 来自原 `kusama.py`. Voronoi Lloyd 主层 + 反密度装饰层 + Canny 边缘 + horror vacui 背景填充, 6 色高饱和板, 硬边实心圆.

**`styles/kusama_depth.py`** — 草间深度感知版. 来自原 `depth_kusama.py`. YOLO26 深度 + 语义分割 + 前景感知深度归一化 + 三层架构 (fine stipple / depth-emphasis / edge+bg) + 跨层剪枝 + 语义双色渲染. 需要 ultralytics + YOLO26 权重 + 推荐 GPU.

### 4.6 `learned.py` — 可学习深度→半径映射

**职责**: IJCAI 论文的 AI 贡献, 用轻量 CNN 替代固定幂律公式.

**类**:
- `DepthRadiusNet` — 4 conv 层 (<50K 参数), 输入 4 通道 (深度 / 亮度 / 深度梯度 / 亮度梯度), 输出半径 + 密度权重
- `StipplePerceptualLoss` — 深度梯度对齐 + 覆盖率 + 半径直方图匹配 + 平滑度

**函数**:
- `train_depth_radius_net(train_images, ...)` — 自监督训练
- `learned_depth_to_radius(model, d_norm, gray, ...)` — 固定 `depth_to_radius` 的可学习替代
- `learned_depth_to_density(model, d_norm, gray, ...)` — 固定 `depth_to_density` 的可学习替代
- `compare_fixed_vs_learned(...)` — 消融对比, 返回固定 vs 可学习的深度-半径相关性等指标

**torch 缺失时**: 类定义占位符, 实例化抛 ImportError; 其余流派完全不受影响.

**来源**: 迁自 `AIforPolkaDotsArt/learned_radius.py`, 调整 `from stippling import compute_density` 为 `from .ops.voronoi import compute_density`.

### 4.7 `api.py` — 统一分派入口

**职责**: 模式注册表 + 统一 `generate(mode, image, **kwargs)` 入口.

**模式分类**:
- `_PURE_MODES` (6 个): seurat / benday / warp / stipple / vogel / kusama_basic — 无 DL 依赖
- `_DL_MODES` (1 个): kusama_depth — 需 ultralytics + YOLO26

**公开 API**:
- `generate(mode, image, **kwargs)` — 统一生成入口
- `MODES` — 完整模式表
- `list_modes() / list_pure_modes() / list_dl_modes()` — 模式列表
- `mode_info(mode)` — 模式元信息 (依赖 / 简述)

### 4.8 `cli.py` — 命令行入口

**子命令**:
- `list` — 列出所有模式 + 依赖 + 简述
- `generate <mode> <input> -o <output> [options]` — 单张生成
- `demo [--input-dir] [--output-dir] [--modes]` — 批量 demo (默认全部纯 numpy 模式)

**入口**: `python -m dotartkit.cli ...` 或 `dotart ...` (pyproject 注册的脚本).

## 5. 接口规范

### 5.1 Python API

```python
from dotartkit import generate
from PIL import Image

img = Image.open("inputs/pumpkin.jpg").convert("RGB")

# 纯 numpy 流派 (任意环境)
out = generate("seurat", img, dot_spacing=6)
out = generate("benday", img, spacing=10, use_pop_palette=True)
out = generate("warp", img, bulge_strength=0.9)
out = generate("stipple", img, n_dots=4000, density_gamma=2.2)
out = generate("vogel", img, n_dots=2200)
out = generate("kusama_basic", img, palette="yellow_black", n_points=20000)

# 深度感知 (需 polkadot-art conda 环境)
out = generate("kusama_depth", img, palette="black_red",
               depth_model_path="models/yolo26x-depth.pt",
               sem_model_path="models/yolo26x-sem.pt",
               alpha=1.5, sigma=0.15, r_max=14.0)
```

### 5.2 命令行

```bash
# 列出所有模式
python -m dotartkit list

# 单张生成
python -m dotartkit generate kusama_basic inputs/pumpkin.jpg -o outputs/out.png --palette yellow_black
python -m dotartkit generate seurat inputs/cat.jpg -o outputs/seurat_cat.png

# 批量 demo (默认全部纯 numpy 模式)
python -m dotartkit demo --input-dir inputs --output-dir outputs/demo

# 深度感知 (需激活 polkadot-art 环境)
conda activate polkadot-art
python -m dotartkit generate kusama_depth inputs/pumpkin.jpg -o outputs/depth.png \
    --palette black_red --r-max 14 --alpha 1.5 --sigma 0.15
```

### 5.3 文件路径接口 (兼容原项目脚本)

## 7. 数学公式汇总

详细推导见 `docs/调研报告_波点艺术流派与数学原理.md` 与 `docs/调研报告_草间弥生风格波点艺术生成.md`, 此处仅列整合包用到的核心公式.

### 7.1 密度场

```
ρ_lum(x,y) = (1 - I_gray(x,y) / 255)^γ                    # 亮度密度 (暗=密)
ρ_depth(x,y) = (1 - d̂(x,y))^β                              # 深度密度 (近=密)
ρ_composite(x,y) = ρ_depth · ρ_lum                          # 深度感知复合密度
```

### 7.2 深度→半径映射

```
d̂(x,y) = (d(x,y) - d_min) / (d_max - d_min)  ∈ [0,1]      # 归一化深度 (0=近, 1=远)
r(x,y) = r_min + (r_max - r_min) · (1 - d̂)^α · (1 + ε)    # 深度→半径
ε ~ N(0, σ²)                                                # 高斯噪声 (手绘有机变化)
```

### 7.3 半调半径

```
coverage a(x) = 1 - g(x)                                    # 覆盖率
r(x) = λ · sqrt(a(x) / π)                                   # Ben-Day 半径
```

### 7.4 Secord 点绘半径

```
r_i ∝ ρ(x_i)^(-1/2)                                         # 密处点小防糊, 疏处点大保墨量
```

### 7.5 Vasarely Vega 凸起位移

```
amp(x,y) = bulge_strength · spacing · 1.6 · (1 - (2r/R - 1)²)   # 抛物线凸起
P' = P + (P - center) / |P - center| · amp                       # 径向向外位移
```

### 7.6 Vogel 黄金角叶序

```
r_n = c · sqrt(n)                                           # 径向距离
θ_n = n · 137.508°                                          # 黄金角
```

### 7.7 草间弥生双峰半径 (原 AIforDotArt 版, 未迁入主包)

```
r_i = r_base · 2.8  with probability 0.06  (大点)
r_i = r_base · U(0.85, 1.15)  otherwise    (小点)
```

## 10. 已知限制与未来方向

### 10.1 已知限制

1. **Cityscapes 语义分类不适用通用照片**: YOLO26x-sem 用 Cityscapes 19 类, 猫会被分为 "person", 南瓜分为 "car". 对前景/背景分离够用, 但语义粒度粗.
2. **scipy 与 numpy 二进制兼容性**: 本机 scipy 1.x 与 numpy 2.x 不兼容, kusama_basic 在此环境下走退化路径 (无 Lloyd 松弛, 点分布质量略降).
3. **Voronoi 计算量**: kusama_basic / kusama_depth 的 Lloyd 松弛 O(n_iter · n_points · cell_size), 大图 (n_points > 30000) 较慢.
4. **未迁移 AIforDotArt 的草间双峰版**: `generate_kusama` (纯数学双峰 + 低频变形场) 与 `kusama_basic` (Voronoi 版) 风格重叠, 整合时取 Voronoi 版. 如需对比, 原实现仍在 `AIforDotArt/dotart.py`.

### 10.2 未来方向

1. **新流派**: 原住民点画 (同心圆 / 路径点采样)、Infinity Nets (无限网, 千条小弧线)、点彩 + 深度感知混合
2. **更好的语义分割**: 用通用分割模型 (SAM2 / OneFormer) 替代 Cityscapes 专用模型
3. **可学习映射集成**: 把 `learned.DepthRadiusNet` 训练后作为 `kusama_depth` 的 `--learned` 选项
4. **交互式调参**: Streamlit / Gradio Web UI 实时预览参数效果
5. **批量处理 CLI**: `dotart batch --input-dir --mode --palette` 批量生成
