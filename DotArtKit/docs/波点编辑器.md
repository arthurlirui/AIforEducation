# 波点艺术编辑器 — 桌面端应用

基于 tkinter 的桌面端波点艺术编辑器: 加载图片 → 深度感知生成 →
可视化编辑 → 导出 PNG. 零新增依赖 (tkinter 随 Python 发行).

## 启动

```bash
cd DotArtKit
py -m dotartkit.gui                        # 空窗口, 手动打开图片
py -m dotartkit.gui inputs/pumpkin.jpg     # 直接加载图片
py -m dotartkit.gui inputs/pumpkin.jpg models   # 指定模型目录
```

## 四类可切换算法

### 1. 深度估计 (`PolkaDocument.ensure_depth`)

| 后端 | 说明 | 依赖 |
|------|------|------|
| `yolo26` | YOLO26x metric depth + Cityscapes 语义分割, 前景感知归一化 | ultralytics + 权重 + GPU |
| `luminance` | 亮度伪深度 (暗=近), 纯 numpy 秒级 | 无 |

深度结果有缓存: 切换其他参数重新生成时不会重跑深度估计.

### 2. 尺寸映射函数 (`ACTIVATIONS`, 10 种)

| 函数 | 公式 | 特性 |
|------|------|------|
| `power` | `r = r_min + (r_max-r_min)(1-f)^α` | 论文默认, α>1 强深度强调 |
| `linear` | `r ∝ (1-f)·α` | 均匀梯度 |
| `sigmoid` | `r ∝ σ(4α(0.5-f))` | S 形, 近/远两端饱和 |
| `sqrt` | `r ∝ (1-f)^(1/α)` | 凹形, 大点为主 |
| `curvature` | `w = clip(0.5+0.5κα, 0, 1)` | 纯曲率对照: 凸面 (球顶) 大点, 凹/鞍面小点 |
| `depth_curv` | `E_geo = (1-f)^α·e^{0.8ακ₊}·(1-0.5κ₋)` | **几何感知主方法**: 深度 × 凸面增益 × 凹面抑制 |
| `log` | `w = 1 - log(1+αf)/log(1+α)` | 对数压缩: 近场剧烈远场平缓 |
| `cosine` | `w = 0.5(1+cos(πf^α))` | 余弦渐变: 平滑半周期 |
| `step` | `w = ⌈(1-f)·n⌉/n, n=⌈4α⌉` | 阶梯量化: 波普硬边风格 |
| `inverse` | `w = f^(1/α)` | 反幂律: 远大近小 (倒置实验) |

全部附带乘性高斯抖动 `·(1+ε), ε~N(0,σ²)` 模拟手绘.

### 2b. 映射特征通道 (`FEATURES`, 6 种)

映射函数的输入特征场 `f` 可任选 (全部归一到 [0,1]).
**方向约定: 低值 = 大点** (与 `(1-f)^α` 型激活一致):

| 特征 | 说明 |
|------|------|
| `depth` | 归一化深度 d̂ (近=0, 远=1) — 默认 |
| `luminance` | 亮度 (暗=0, 亮=1 — 暗处大点, 经典点绘) |
| `curvature` | 平均曲率 κ (凹/鞍=1, 凸=0 — 凸面大点) |
| `gradient` | 深度梯度模 |∇d̂| (平坦=0, 转折=1 — 平坦处大点) |
| `gaussian_curv` | 高斯曲率 K (球顶=0, 鞍=1 — 球顶大点) |
| `hybrid` | 混合 0.6·d̂ + 0.4·(1-κ₊) (近+凸 → 低值 → 大点) |

特征场计算按图像缓存; **10 映射 × 6 特征 = 60 种组合**.

### 2c. 再编辑: 半径重映射 (`remap_radii`)

不重新采样 — 保留点位置 (含手动增删移动过的点), 只按当前
映射函数+特征重算半径:

- **全部点重映射**: 参数面板「全部点重映射」按钮
- **选区重映射**: 画布 Ctrl+左键拖出圆形选区 (橙色虚线) 后
  点「选区重映射」— 选区外的点半径不动
- 全部入撤销历史 (Ctrl+Z 可回退)

**曲率场 κ** (`ops/geometry.py`): 深度图视为高度场 h=1-d̂, 计算平均曲率
(高斯平滑 σ=1.5 抑制二阶噪声) 并符号化归一到 [-1,1]:
κ>0 凸面 (如南瓜主体鼓起), κ<0 凹/鞍面 (表面转折带). 曲率场按深度
结果缓存, 切换其他参数重新生成时不重算.

**E_geo 的效果** (pumpkin 实测, YOLO26 深度):
`depth_curv` 相对 `power` 点半径与曲率的相关系数从 0.009 → 0.062,
与深度的相关从 0.198 → 0.301; 表面转折带由"少量巨点"变为"大量中点"
(最大 blob 0.39% → 0.11%), 更顺应曲面. 可学习网络 (`learned.py`)
同步升级: 输入 4→6 通道 (+κ, +高斯曲率符号), 损失新增曲率对齐项
(凸面半径放大) 与凹面密度加密项 (κ<0 处更密的点顺应表面转折).

### 3. 波点滤除算法 (`FILTERS`)

| 算法 | 行为 |
|------|------|
| `none` | 保留全部采样点 |
| `overlap` | 两圆间距 < r1+r2+gap 删其一 (默认) |
| `min_dist` | 圆心距 < gap 删其一 |
| `density` | 局部过密处随机稀疏化, 疏区全保留 |

### 4. 配色方案 (`DEPTH_PALETTES`)

共 **10 套**, 每套含 背景色 + 前景点色 + 背景点色 三元组:

经典 5 套: `black_red` / `yellow_black` / `white_red` /
`magenta_cyan` / `red_yellow`

艺术扩展 5 套: `navy_gold` (海军蓝×香槟金, Klimt 金色时期) /
`emerald_white` (祖母绿×象牙白, Art Deco) /
`purple_orange` (深紫×橙, 星夜互补) /
`sakura_charcoal` (樱花粉×炭黑, 和风) /
`teal_coral` (深青×珊瑚橙, 热带现代)

## 编辑工具

| 工具 | 快捷键 | 操作 |
|------|--------|------|
| 选择/移动 | `V` | 点击选中 (绿框+半径柄); 拖拽移动; 滚轮改半径; `Delete` 删除 |
| 添加 | `A` | 点击空白处按笔刷半径加点; `Shift+点击` = 背景角色 |
| 擦除 | `E` | 点击删点; 按住拖动连续擦除圆域 |

- `Ctrl+Z` / `Ctrl+Y` 撤销/重做 (最多 50 步, 生成操作同样可撤销)
- 右键拖动平移, 滚轮缩放 (以鼠标位置为不动点)

## 架构

```
dotartkit/gui/
├── polka_document.py   核心文档模型 (无 tkinter 依赖, 可独立测试)
│   ├── PolkaDocument   图像 + 深度/密度场 + 点列表 + undo/redo
│   ├── DEPTH_BACKENDS  深度估计注册表
│   ├── ACTIVATIONS     激活函数注册表
│   └── FILTERS         滤除算法注册表
└── polka_app.py        tkinter UI (工具栏/参数面板/画布/状态栏)
    ├── PolkaApp        主窗口, 后台线程生成 + UI 轮询结果
    └── CanvasView      画布视图: 坐标变换/缩放平移/编辑事件
```

关键设计:
- **生成与编辑解耦** — 点列表是唯一事实来源, 渲染 = f(点列表, 调色板);
  编辑只改点列表. 换配色/改单点无需重新采样.
- **tkinter 线程安全** — 后台线程不触碰 tkinter 变量: 生成参数在
  UI 线程快照后传入, 结果通过轮询取回.
- **渲染缓存** — 仅在点集或配色变更时重渲染 (`invalidate_render`).
