# 艺境 ArtRealm3D · 设计文档

> 世界名画三维沉浸式体验教学服务平台 — 设计与实现
> 版本 0.1.0 · 2026-11-01

## 1. 目标与定位

为艺术教学构建一个"可走进去的美术馆"：不是展示一张平面图片，而是把名画
**解构为带深度的三维空间**，用动态叙事讲解它的构图、时代背景与精神内核，
并以测验形成教学闭环。

核心教学理念：

1. **空间化理解** —— 构图不是平面的，前景丝柏、中景村庄、远景星空的层次
   关系在 3D 视差中一目了然；
2. **叙事驱动注意力** —— 每个章节把镜头推向正在讲解的那一层，讲述与观看同步；
3. **从形式到内核** —— 章节弧线固定为：intro → 构图(composition) →
   背景(background/technique) → 精神内核(spirit) → epilogue。

## 3. 关键设计决策

### 3.1 三维表示：程序化分层，而非照片贴图

**决策**：不用原图照片（版权 + 无法分层），而是为每幅画手写"风格处方"——
每层一个渲染风格键 + 调色板 + 几何语义参数，由确定性渲染器（numpy+PIL）
离屏绘制成 RGBA PNG。

- 优点：零外部资产依赖、可任意调整层次深度、同处方字节级可复现、便于扩展
- 图层透明度：只有三种背景风格（night-sky / wave-sky / dark-void）不透明，
  其余层近黑像素（<12 阈值，容忍笔触噪声）alpha 置 0，保证 3D 合成正确
- 缓存：资产按 `(画id, layers签名)` 落盘，处方不变则不重渲染

### 3.2 深度与镜头语言

每层带 `depth`（正=前景）。前端将其映射为 z 轴位置（×0.42），并实现五种镜头：
overview（全景）、medium / close-up / extreme-close-up（对目标层推近，zoom
控制距离）、pull-back（尾声拉远）。镜头插值用逐帧 lerp，与鼠标视差叠加。

### 3.3 叙事即数据

章节完全数据驱动（id/type/title/subtitle/text/focus/duration），前端不包含
任何画作特定逻辑。新增一幅画 = 知识库加一条记录，前端零改动。

### 3.4 教学闭环

导览最后一章"去测验 →"直接路由到 `/quiz/:id`；测验提交后端判分，返回
逐题正误 + 艺术史解析，前端按分数段给出鼓励性评语。

## 5. 已知限制与后续路线

- 视觉为程序化"致敬风格"，非原作复现；后续可接入 TripoSplat 等做真 3D lifting
- 语音朗读依赖浏览器 SpeechSynthesis（Chromium 中文音色有限）
- 叙事文本为手工撰写；后续可接 LLM 按知识库生成多语言/多深度版本
- 名画数量 3 幅；扩展只需加知识库条目（见 README）
- 可加：学习进度持久化、教师端出题、多人同览
